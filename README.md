# 미션 - 크리스마스 프로모션

# 기능 목록
**1. [출력] 인삿말을 출력한다.**

**2. [입력] 방문 날짜를 입력받는다.**
   - [예외 처리] 정수 타입이 아닐 경우 예외를 발생시킨다.
   - [예외 처리] 1 ~ 31 사이의 숫자가 아닐 경우 예외를 발생시킨다.

**3. [중간 과정] 크리스마스 디데이 할인 여부를 계산한다.**

**4. [중간 과정] 평일, 주말 할인 여부를 계산한다.**

**5. [중간 과정] 특별 할인 여부를 계산한다.**

**6. [입력] 주문 정보(메뉴, 수량)를 입력받는다.**
   - [예외 처리] 메뉴 형식이 예시와 다른 경우 예외를 발생시킨다.
   - [예외 처리] 메뉴판에 없는 메뉴일 경우 예외를 발생시킨다.
   - [예외 처리] 메뉴의 개수가 정수 타입이 아니거나 1보다 작을 경우 예외를 발생시킨다.
   - [예외 처리] 중복 메뉴를 입력한 경우 예외를 발생시킨다.

**7. [중간 과정] 증정 이벤트 여부를 계산한다.**

**8. [출력] 방문일에 받을 이벤트 혜택을 출력한다.**
   - 주문 메뉴(출력 순서 자유롭게)
   - 할인 전 총주문 금액
   - 증정 메뉴(해당 X -> 없음)
   - 혜택 내역(적용 이벤트 X -> 없음)
   - 총혜택 금액(할인 금액의 합계 + 증정 메뉴의 가격)
   - 할인 후 예상 결제 금액(할인 전 총주문 금액 - 할인 금액)
   - 12월 이벤트 배지(부여 X -> 없음)
